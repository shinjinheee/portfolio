### 용량 관리

설계서 §2는 "zip 20MB 이하"가 목표다. 현재 아카이브만 4.1MB.
케이스 이미지가 붙으면 초과 위험이 있으므로 **WebP 변환**을 전제로 진행한다.

```bash
# PNG → WebP (품질 82, 보통 70~80% 감소)
for f in assets/img/archive/*.png; do
  cwebp -q 82 "$f" -o "${f%.png}.webp"
done
```

`<picture>` 태그로 PNG 폴백을 두면 사내망·구형 브라우저에서도 안전하다.
