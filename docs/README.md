## 값이 충돌할 때

`01`은 구 PSD 기준이고 Figma 시안은 그 이후에 갱신됐다.
**수치는 `02`의 실측값을, 구성·논리는 `01`을 따른다.**

`02` §5에 결정이 필요한 항목을 모아뒀다. 구현 전에 여기부터 정리한다.

## Figma 재측정

토큰은 `~/.figma_token` (권한 600, 스코프 `File content: Read-only`).
Figma MCP나 유료 플랜은 필요 없다.

```bash
curl -sS -H "X-Figma-Token: $(cat ~/.figma_token)" \
  "https://api.figma.com/v1/files/cSxRlT09bjzhzOsK6pXTyS/nodes?ids=40:23208"
```

| 대상 | 노드 ID |
|---|---|
| 전체 섹션 | `40:23208` |
| index 페이지 프레임 (1920×6322) | `1:2` |
| 아카이브 캐러셀 정본 (14장) | `40:23144` |

> `1:2` 안의 `Frame 93`에도 아카이브가 있지만 10장짜리 **구버전**이다.
