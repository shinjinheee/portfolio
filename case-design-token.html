결과

  • PD·FE 작업 효율 40% 상승
  • 월 핸드오프 수치 재확인 요청 감소

키워드

디자인 시스템 AI Variables Design.md
Background Result Approach What's improved? Output

Background

PD·FE와의 합의 부재로 반복되는 스타일 값 전달 비용 제거

Grid·Spacing·Font·Effect·Border Radius를 Design Token으로 정의하고 Figma Variables로 관리했으며, 구축된 구조를 기반으로 Component·Color 정의를 design.md 명세로 정리해 개발에 전달했어요.

Result

PD·FE와의 합의 부재로 반복되는 스타일 값 전달 비용 제거

공통 기준이 생기자 디자이너와 개발자의 작업 방식이 달라졌어요.

Approach

공유 가능한 기준이 없던 세 레이어의 구조화

스타일 값 구조화부터 컬러 체계화, 명세 문서화까지 세 레이어를 순차적으로 정비해 반복되던 수동 전달 비용을 줄이고자 했어요.

What's improved?

Variables 구조화 - 스타일 기준 일원화

수치를 외우거나 매번 전달하던 구조에서, Design Token으로 즉시 참조하는 구조로 개선

What's improved?

Color Token 구축 - 컬러 기준 체계화

컬러 값을 외우거나 복사하던 방식에서, Semantic Color Token으로 용도 기반 즉시 적용으로 개선

What's improved?

토큰 명세 문서화 - 공유 가능한 핸드오프

매번 구두로 다시 설명하던 컴포넌트·토큰 사용 규칙을, design.md 단일 명세로 모아 변경이 생겨도 개발이 같은 문서를 참조하는 구조로 개선

Output

3단계 구조의 변경

Approach

제품이 늘어도 기준은 하나 문서는 자동으로 처리

디자인 산출물을 만드는 데서 끝나지 않고, 디자인 정보가 개발까지 흐르는 구조를 설계했어요. 구조화·체계화·문서화가 하나의 흐름으로 연결될 때 비로소 반복 비용이 줄어들었어요.
